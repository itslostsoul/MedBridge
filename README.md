MedBridge 🏥
MedBridge is a full-stack healthcare web application designed to optimize patient data management and improve digital medical accessibility. It features dynamic templates and robust backend logic to streamline clinical workflows and data tracking. 💻✨

Features 🚀
Patient Data Management: Efficiently handle and track medical records and patient information. 🗂️

Streamlined Workflows: Designed to simplify clinical processes and digital access. 🌐

Dynamic Frontend & Backend Integration: Built with responsive layouts paired with a reliable server-side architecture. ⚙️

Tech Stack 🛠️
Backend: Python, Flask

Database: SQL

Frontend: HTML, CSS, JavaScript
